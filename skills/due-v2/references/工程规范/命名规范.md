# 命名规范

## 1. 全表

| 对象 | 规范 | 正确 | 错误 |
| --- | --- | --- | --- |
| 包名 / 目录 | 全小写、单数、无下划线；目录名 = 包名 | `route` `logic` | `Route` `route_group` |
| 文件 | snake_case | `table_logic.go` | `TableLogic.go` `tableLogic.go` |
| 导出类型 / 函数 | PascalCase | `TableLogic` `NewRoom` | `tableLogic` |
| 非导出 | camelCase | `newRoom` | `new_room` |
| 接口 | 名词或 `-er` | `Matcher` `Player` | `IMatcher` |
| 枚举 | `type X int` + `const` 块 | `type State int` | 裸 const |
| 路由常量 | 集中包 + 语义命名 | `route.Login` | `1`、`LOGIN_ROUTE` |
| 协议消息 | 成对 `XxxReq` / `XxxRes` | `LoginReq` / `LoginRes` | `LoginRequest` |
| 错误码 | 统一登记，禁止硬编码数字 | `code.OK` | `401` |
| 服务 / app 名 | kebab-case | `hall` `game-demo` | `Hall` `game_demo` |
| 事件 topic | `<domain>:<action>` | `user:register` | `USER_REGISTER` |
| DB 表 | snake_case、单数 | `user` `game_record` | `Users` `gameRecord` |
| DB 字段 | snake_case | `created_at` | `createdAt` |
| 配置项 | 小驼峰 | `maxConnNum` | `max_conn_num` |
| 注释 | 一律中文 | `// 校验令牌` | `// validate token` |

## 2. 脱敏（硬规则）

文档、示例、注释中一律使用**占位名**，禁止出现真实信息：

- 真实项目名 / 仓库名 → 用 `<repo>`、`example-server`
- 真实 app / 部署名 → 用 `game-demo`、`<service>`
- 真实域名 / 包路径 → 用 `discovery://<domain>`、`<module>/internal/...`
- 真实密钥 / 账号 → 一律不出现

## 3. 常量与号段

- 路由号、状态枚举等**集中定义**，并在 `define` 登记号段占用情况。
- 同一含义只允许一个名字，禁止别名满天飞。
- 枚举首值留零值作"无效/未设置"。

## 4. 反模式

- 目录名与包名不一致（`utils` 目录里 `package helper`）。
- 用下划线或大小写在 Go 标识符里（`new_room`、`Newroom`）。
- 路由号在各文件里裸写数字。
- 错误码在业务里硬编码数字。
- 注释用英文（本类项目约定中文）。
