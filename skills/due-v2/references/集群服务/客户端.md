# 客户端 (Client)

## 概述

客户端是 Due 框架的调试和测试组件，提供便捷的客户端开发能力。支持 TCP 和 WebSocket 协议，可用于开发调试、压测等场景。

## 包路径

```go
import "github.com/dobyte/due/v2/cluster/client"
```

## TCP 客户端配置

```toml
[cluster.client]
    # 实例ID，集群中唯一。不填写默认自动生成唯一的实例ID
    id = ""
    # 实例名称
    name = "client"
    # 编解码器。可选：json | proto。默认为proto
    codec = "json"

[network.tcp.client]
    # 拨号地址
    addr = "127.0.0.1:3553"
    # CA证书文件
    caFile = ""
    # 证书域名
    serverName = ""
    # 拨号超时时间，支持单位：纳秒（ns）、微秒（us | µs）、毫秒（ms）、秒（s）、分（m）、小时（h）、天（d）。默认为3s
    dialTimeout = "3s"
    # 写入超时时间，默认0s（不超时）
    writeTimeout = "0s"
    # 写入队列大小，默认1024
    writeQueueSize = 1024
    # 心跳间隔时间；设置为0则不启用心跳检测，默认为10s
    heartbeatInterval = "10s"
    # 优雅关闭超时时间，默认0s（不限制）
    closeTimeout = "0s"

[packet]
    # 字节序，默认为big。可选：little | big
    byteOrder = "big"
    # 路由字节数，默认为2字节
    routeBytes = 2
    # 序列号字节数，默认为2字节
    seqBytes = 2
    # 消息字节数，默认为5000字节
    bufferBytes = 5000
    # 是否携带服务器心跳时间
    heartbeatTime = false
```

## 核心 API

### 创建客户端组件

```go
// 创建客户端组件
func NewClient(opts ...Option) *Client

// 选项函数
func WithID(id string) Option
func WithName(name string) Option
func WithCodec(codec encoding.Codec) Option
func WithClient(client network.Client) Option
func WithContext(ctx context.Context) Option
func WithEncryptor(encryptor crypto.Encryptor) Option

// 拨号选项
func WithDialAddr(addr string) DialOption
func WithConnAttr(key string, value any) DialOption
```

### 客户端代理

```go
type Proxy struct {
    // 实例信息
    ID() string
    Name() string
    // 拨号连接
    Dial(opts ...DialOption) (*Conn, error)
    // 获取底层网络客户端
    Client() network.Client
    // 添加路由处理器
    AddRouteHandler(route int32, handler RouteHandler)
    // 设置默认路由处理器
    SetDefaultRouteHandler(handler RouteHandler)
    // 添加事件监听
    AddEventListener(event cluster.Event, handler EventHandler)
    // 添加钩子监听
    AddHookListener(hook cluster.Hook, handler HookHandler)
}
```

### 连接

```go
type Conn struct {
    // 连接与用户信息
    ID() int64
    UID() int64
    Bind(uid int64)
    Unbind()
    // 连接属性
    SetAttr(key, value any)
    GetAttr(key any) value.Value
    DelAttr(key any)
    // 地址信息
    LocalIP() (string, error)
    LocalAddr() (net.Addr, error)
    RemoteIP() (string, error)
    RemoteAddr() (net.Addr, error)
    // 推送消息
    Push(message *cluster.Message) error
    // 关闭连接
    Close() error
}
```

### 上下文

```go
type Context struct {
    // 获取底层上下文
    Context() context.Context
    // 连接与用户信息
    CID() int64
    UID() int64
    Conn() *Conn
    // 消息信息
    Seq() int32
    Route() int32
    Data() any
    // 解析响应
    Parse(v any) error
}
```

## TCP 客户端示例

```go
package main

import (
    "fmt"
    "time"
    "github.com/dobyte/due/network/tcp/v2"
    "github.com/dobyte/due/v2"
    "github.com/dobyte/due/v2/cluster"
    "github.com/dobyte/due/v2/cluster/client"
    "github.com/dobyte/due/v2/log"
    "github.com/dobyte/due/v2/utils/xtime"
)

// 路由号
const greet = 1

func main() {
    // 创建容器
    container := due.NewContainer()
    // 创建客户端组件
    component := client.NewClient(
        client.WithClient(tcp.NewClient()),
    )
    // 初始化监听
    initApp(component.Proxy())
    // 添加客户端组件
    container.Add(component)
    // 启动容器
    container.Serve()
}

// 初始化应用
func initApp(proxy *client.Proxy) {
    // 监听组件启动
    proxy.AddHookListener(cluster.Start, startHandler)
    // 监听连接建立
    proxy.AddEventListener(cluster.Connect, connectHandler)
    // 监听消息回复
    proxy.AddRouteHandler(greet, greetHandler)
}

// 组件启动处理器
func startHandler(proxy *client.Proxy) {
    if _, err := proxy.Dial(); err != nil {
        log.Errorf("connect server failed: %v", err)
        return
    }
}

// 连接建立处理器
func connectHandler(conn *client.Conn) {
    doPushMessage(conn)
}

// 消息回复处理器
func greetHandler(ctx *client.Context) {
    res := &greetRes{}

    if err := ctx.Parse(res); err != nil {
        log.Errorf("invalid response message, err: %v", err)
        return
    }

    if res.Code != 0 {
        log.Errorf("node response failed, code: %d", res.Code)
        return
    }

    log.Info(res.Message)

    time.AfterFunc(time.Second, func() {
        doPushMessage(ctx.Conn())
    })
}

// 请求
type greetReq struct {
    Message string `json:"message"`
}

// 响应
type greetRes struct {
    Code    int    `json:"code"`
    Message string `json:"message"`
}

// 推送消息
func doPushMessage(conn *client.Conn) {
    if err := conn.Push(&cluster.Message{
        Route: 1,
        Data: &greetReq{
            Message: fmt.Sprintf("I'm client, and the current time is: %s", xtime.Now().Format(xtime.DateTime)),
        },
    }); err != nil {
        log.Errorf("push message failed: %v", err)
    }
}
```

## 最佳实践

1. **连接管理**:
   - 合理设置心跳间隔保持连接活跃
   - 处理连接断开和重连逻辑

2. **消息处理**:
   - 使用路由号区分不同类型的消息
   - 实现异步消息处理提高性能

3. **错误处理**:
   - 处理连接失败的情况
   - 实现重试机制提高可靠性

4. **性能优化**:
   - 使用连接池管理多个连接
   - 合理设置超时时间

5. **调试技巧**:
   - 使用日志记录关键事件
   - 实现详细的错误信息输出
