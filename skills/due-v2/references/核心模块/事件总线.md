# 事件总线 (EventBus)

## 概述

事件总线（`eventbus` 包）是 Due 框架的核心组件，提供发布-订阅模式的事件通信能力，用于实现模块间、进程间的松耦合通信。框架提供了 process（进程内）、nats、redis、kafka 四种实现。

## 包路径

```go
import "github.com/dobyte/due/v2/eventbus"

// 进程内实现（随框架主模块发布）
import "github.com/dobyte/due/v2/eventbus/process"

// 远程实现为独立子模块
import (
    "github.com/dobyte/due/eventbus/nats/v2"
    "github.com/dobyte/due/eventbus/redis/v2"
    "github.com/dobyte/due/eventbus/kafka/v2"
)
```

## 核心 API

### 事件总线接口

```go
type Eventbus interface {
    // 关闭事件总线
    Close() error
    // 发布事件
    Publish(ctx context.Context, topic string, message any) error
    // 订阅事件。balance 为 true 时使用竞争消费模式（负载均衡）
    Subscribe(ctx context.Context, topic string, handler EventHandler, balance ...bool) (Subscription, error)
}

type Subscription interface {
    // 取消订阅
    Unsubscribe(ctx context.Context) error
}
```

包级快捷函数（操作全局事件总线）：

```go
// 设置全局事件总线
func SetEventbus(eb Eventbus)
// 获取全局事件总线
func GetEventbus() Eventbus
// 发布事件
func Publish(ctx context.Context, topic string, message any) error
// 订阅事件
func Subscribe(ctx context.Context, topic string, handler EventHandler, balance ...bool) (Subscription, error)
// 关闭全局事件总线
func Close() error
```

### 事件处理器

```go
type EventHandler func(event *Event)

type Event struct {
    ID        string      // 事件ID
    Topic     string      // 事件主题
    Payload   value.Value // 事件负载
    Timestamp time.Time   // 事件时间
}
```

## 使用场景示例

### 基础使用

```go
package main

import (
    "context"
    "github.com/dobyte/due/v2/eventbus"
    "github.com/dobyte/due/v2/eventbus/process"
)

func main() {
    // 设置全局事件总线（进程内实现）
    eventbus.SetEventbus(process.NewEventbus())

    ctx := context.Background()

    // 订阅事件
    _, err := eventbus.Subscribe(ctx, "user.login", func(evt *eventbus.Event) {
        var userID int64
        if err := evt.Payload.Scan(&userID); err != nil {
            return
        }
        println("User logged in:", userID)
    })
    if err != nil {
        panic(err)
    }
    
    // 发布事件
    _ = eventbus.Publish(ctx, "user.login", int64(1001))
}
```

### 多个订阅者

```go
package main

import (
    "context"
    "github.com/dobyte/due/v2/eventbus"
    "github.com/dobyte/due/v2/eventbus/process"
)

func main() {
    eventbus.SetEventbus(process.NewEventbus())
    
    ctx := context.Background()
    
    // 订阅者1
    eventbus.Subscribe(ctx, "user.register", func(evt *eventbus.Event) {
        println("Subscriber 1: User registered")
    })
    
    // 订阅者2
    eventbus.Subscribe(ctx, "user.register", func(evt *eventbus.Event) {
        println("Subscriber 2: User registered")
    })
    
    // 发布事件，所有订阅者都会收到
    _ = eventbus.Publish(ctx, "user.register", nil)
}
```

### 异步事件

```go
package main

import (
    "context"
    "time"
    "github.com/dobyte/due/v2/eventbus"
    "github.com/dobyte/due/v2/eventbus/process"
)

func main() {
    eventbus.SetEventbus(process.NewEventbus())
    
    ctx := context.Background()
    
    // process 实现通过任务池异步分发事件处理器
    eventbus.Subscribe(ctx, "user.action", func(evt *eventbus.Event) {
        time.Sleep(1 * time.Second)
        println("Async event processed")
    })
    
    // 发布事件，不阻塞
    _ = eventbus.Publish(ctx, "user.action", nil)
    
    println("Event published")
    
    // 等待异步事件处理完成
    time.Sleep(2 * time.Second)
}
```

### 取消订阅

```go
package main

import (
    "context"
    "github.com/dobyte/due/v2/eventbus"
    "github.com/dobyte/due/v2/eventbus/process"
)

func main() {
    eventbus.SetEventbus(process.NewEventbus())
    
    ctx := context.Background()
    
    // 订阅事件，返回订阅句柄
    sub, err := eventbus.Subscribe(ctx, "user.logout", func(evt *eventbus.Event) {
        println("Event received")
    })
    if err != nil {
        panic(err)
    }
    
    // 发布事件
    _ = eventbus.Publish(ctx, "user.logout", nil)
    
    // 取消订阅
    _ = sub.Unsubscribe(ctx)
    
    // 再次发布事件，处理器不会被调用
    _ = eventbus.Publish(ctx, "user.logout", nil)
}
```

### 在节点服务器中使用

```go
package main

import (
    "context"
    "github.com/dobyte/due/v2/cluster"
    "github.com/dobyte/due/v2/cluster/node"
    "github.com/dobyte/due/v2/eventbus"
    "github.com/dobyte/due/v2/eventbus/process"
)

func main() {
    eventbus.SetEventbus(process.NewEventbus())
    
    ctx := context.Background()
    
    // 创建节点组件
    component := node.NewNode()
    
    // 获取节点代理
    proxy := component.Proxy()
    
    // 监听节点启动 Hook（Hook 常量定义在 cluster 包中）
    proxy.AddHookListener(cluster.Start, func(proxy *node.Proxy) {
        println("Node started")
        
        // 发布自定义事件
        _ = eventbus.Publish(ctx, "node.ready", nil)
    })
    
    // 订阅自定义事件
    eventbus.Subscribe(ctx, "node.ready", func(evt *eventbus.Event) {
        println("Node is ready")
    })
}
```

### 在网关服务器中使用

```go
package main

import (
    "context"
    "github.com/dobyte/due/v2/cluster/gate"
    "github.com/dobyte/due/v2/eventbus"
    "github.com/dobyte/due/v2/eventbus/process"
)

func main() {
    eventbus.SetEventbus(process.NewEventbus())
    
    ctx := context.Background()
    
    // 创建网关组件
    _ = gate.NewGate()
    
    // 说明：网关在连接建立/重连/断开时会向业务节点触发 cluster.Connect、
    // cluster.Reconnect、cluster.Disconnect 事件；如需跨节点/跨进程广播
    // 连接情况，可通过事件总线发布自定义事件实现。
    eventbus.Subscribe(ctx, "client.connect", func(evt *eventbus.Event) {
        var connID int64
        if err := evt.Payload.Scan(&connID); err != nil {
            return
        }
        println("Client connected:", connID)
    })
    
    // 发布连接事件
    _ = eventbus.Publish(ctx, "client.connect", int64(1001))
}
```

## 事件类型

### 系统事件

eventbus 本身不预定义事件主题；Due 框架在 `cluster` 包中定义了组件生命周期 Hook 与连接事件，可用于命名与驱动业务事件：

```go
// 组件生命周期 Hook（定义在 cluster 包中）
const (
    Init    Hook = iota // 初始化
    Start               // 启动
    Close               // 关闭
    Destroy             // 销毁
)

// 连接事件（定义在 cluster 包中）
const (
    Connect    Event = iota + 1 // 连接建立
    Reconnect                   // 连接重连
    Disconnect                  // 连接断开
)
```

### 自定义事件

```go
package main

import (
    "context"
    "github.com/dobyte/due/v2/eventbus"
    "github.com/dobyte/due/v2/eventbus/process"
)

const (
    UserLogin    = "user.login"
    UserLogout   = "user.logout"
    UserRegister = "user.register"
)

func main() {
    eventbus.SetEventbus(process.NewEventbus())
    
    ctx := context.Background()
    
    // 订阅自定义事件
    eventbus.Subscribe(ctx, UserLogin, handleUserLogin)
    eventbus.Subscribe(ctx, UserLogout, handleUserLogout)
    eventbus.Subscribe(ctx, UserRegister, handleUserRegister)
    
    // 发布自定义事件
    _ = eventbus.Publish(ctx, UserLogin, map[string]any{
        "user_id":  1001,
        "username": "alice",
    })
}

func handleUserLogin(evt *eventbus.Event) {
    var userInfo struct {
        Username string `json:"username"`
    }
    if err := evt.Payload.Scan(&userInfo); err != nil {
        return
    }
    println("User logged in:", userInfo.Username)
}

func handleUserLogout(evt *eventbus.Event) {
    println("User logged out")
}

func handleUserRegister(evt *eventbus.Event) {
    println("User registered")
}
```

## 最佳实践

1. **事件命名**:
   - 使用清晰的命名规范，如 `module.action`
   - 例如：`user.login`、`order.create`

2. **异步处理**:
   - 事件处理器由实现异步分发（如 process 通过任务池、远程实现通过消费协程），但耗时操作仍应避免阻塞消费
   - 避免在处理器中执行阻塞主业务流程的操作

3. **错误处理**:
   - 在事件处理器中处理错误
   - 不要让错误影响其他订阅者

4. **资源管理**:
   - 及时取消不需要的订阅
   - 避免内存泄漏

5. **线程安全**:
   - 事件处理器要考虑并发安全
   - 使用锁或原子操作保护共享数据

6. **性能优化**:
   - 避免在事件处理器中执行重操作
   - 对于需要负载均衡的消费场景，订阅时使用 `balance = true` 以启用竞争消费
