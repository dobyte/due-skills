# 加密签名 (Crypto)

## 概述

加密签名模块是 Due 框架的核心组件,提供数据加密、解密、签名、验签等安全能力。支持 RSA、ECC(ECIES/ECDSA)等非对称加密算法,保障数据传输安全。

> **v2.6.3 Breaking Changes**(本次升级期间生效):
> 1. `crypto.RegisterEncryptor` / `crypto.InvokeEncryptor` / `crypto.RegisterSigner` / `crypto.InvokeSigner` **四个全局注册/查找函数全部移除**;各独立子模块(RSA/ECC)各自提供 `NewEncryptor` / `NewSigner` 工厂函数直接使用,不再有全局注册中心
> 2. `crypto.Verifier` 接口整体移除,Verifier 功能合并进 `crypto.Signer.Verify` 方法
> 3. `[crypto.rsa.verifier]` / `[crypto.ecc.verifier]` 配置节不再读取(Verifier 移除)
> 4. `crypto/{aead,aesgcm,chacha20poly1305,handshake}` 会话安全组件**从 crypto 包移到 `github.com/dobyte/due/v2/core/security`**,包含 X25519 密钥交换 + HKDF 派生 + AES-256-GCM/ChaCha20-Poly1305 AEAD + 64-bit replay window
> 5. `WithEnableTamperProtection` Option / `etc.cluster.{client,node}.enableTamperProtection` / `errors.ErrTamperedMessage` **全部移除**,改用 `WithSessionSecurity`

## RSA 加密

### 配置参数

```toml
[crypto.rsa.encryptor]
    # hash算法,不区分大小写。可选:SHA1 | SHA224 | SHA256 | SHA384 | SHA512。默认为SHA256
    hash = "SHA256"
    # 填充规则,不区分大小写。可选:NORMAL(PKCS#1 v1.5) | OAEP。默认为OAEP(v2.6.3起)
    padding = "OAEP"
    # 标签,加解密时必需一致
    label = ""
    # 加密数据块大小,单位字节。默认为0(使用填充规则允许的最大块大小)
    blockSize = 0
    # 公钥,可设置文件路径或公钥串(加密用)
    publicKey = ""
    # 私钥,可设置文件路径或私钥串(解密用)
    privateKey = ""

[crypto.rsa.signer]
    # hash算法,不区分大小写。可选:SHA1 | SHA224 | SHA256 | SHA384 | SHA512
    hash = "SHA256"
    # 填充规则,不区分大小写。可选:PKCS | PSS。默认为PSS
    padding = "PSS"
    # 公钥,可设置文件路径或公钥串(验签用)
    publicKey = ""
    # 私钥,可设置文件路径或私钥串(签名用)
    privateKey = ""
```

### 使用示例

```go
package main

import (
    "github.com/dobyte/due/crypto/rsa/v2"
)

func main() {
    // 创建RSA加密器(公钥用于加密,私钥用于解密)
    encryptor := rsa.NewEncryptor(
        rsa.WithEncryptorPublicKey("./etc/rsa/public.pem"),
        rsa.WithEncryptorPrivateKey("./etc/rsa/private.pem"),
        rsa.WithEncryptorPadding(rsa.OAEP),
    )

    // 加密数据
    ciphertext, err := encryptor.Encrypt([]byte("hello world"))
    if err != nil {
        panic(err)
    }

    // 解密数据
    plaintext, err := encryptor.Decrypt(ciphertext)
    if err != nil {
        panic(err)
    }

    println(string(plaintext))
}
```

## ECC 加密

ECC 使用 ECIES 加解密、ECDSA 签名验签,基于椭圆曲线,密钥更短。支持 P224、P256、P384、P521 曲线。

### 配置参数

```toml
[crypto.ecc.encryptor]
    # 共享信息,加解密时必需一致
    s1 = ""
    # 共享信息,加解密时必需一致
    s2 = ""
    # 公钥,可设置文件路径或公钥串(加密用)
    publicKey = ""
    # 私钥,可设置文件路径或私钥串(解密用)
    privateKey = ""

[crypto.ecc.signer]
    # hash算法,不区分大小写。可选:SHA1 | SHA224 | SHA256 | SHA384 | SHA512
    hash = "SHA256"
    # 签名分隔符。ECDSA签名会产生两段签名串,需通过分隔符拼接为一个签名
    delimiter = " "
    # 公钥,可设置文件路径或公钥串(验签用)
    publicKey = ""
    # 私钥,可设置文件路径或私钥串(签名用)
    privateKey = ""
```

### 使用示例

```go
package main

import (
    "github.com/dobyte/due/crypto/ecc/v2"

func main() {

        panic(err)
    }

    // 解密数据

    if err != nil {
        panic(err)
    }

}
```

## 数字签名

### RSA 签名示例

```go
package main

import (
    "github.com/dobyte/due/crypto/rsa/v2"
)

func main() {
    // 创建RSA签名器(私钥用于签名,公钥用于验签)
    signer := rsa.NewSigner(
        rsa.WithSignerPrivateKey("./etc/rsa/private.pem"),
        rsa.WithSignerPublicKey("./etc/rsa/public.pem"),
        rsa.WithSignerPadding(rsa.PSS),
    )

    data := []byte("hello world")

    // 签名
    signature, err := signer.Sign(data)
    if err != nil {
        panic(err)
    }

    // 验签
    valid, err := signer.Verify(data, signature)
    if err != nil {
        panic(err)
    }
    if valid {
        println("Signature is valid")
    } else {
        println("Signature is invalid")
    }
}
```

## 核心 API

### 加密器接口

```go
// crypto.Encryptor — v2.6.8 源码实际接口（极简三方法，无全局注册）
type Encryptor interface {
    // Name 返回加密器名称
    Name() string
    // Encrypt 加密数据
    Encrypt(data []byte) ([]byte, error)
    // Decrypt 解密数据
    Decrypt(data []byte) ([]byte, error)
}
```

> ⚠️ **v2.6.3 Breaking**: `crypto.RegisterEncryptor` / `crypto.InvokeEncryptor` 全局注册/查找函数**已移除**。各独立子模块（`crypto/rsa`、`crypto/ecc`）各自 `NewEncryptor(...)` 工厂函数直接构造，不再经由全局注册中心。

### 签名器接口

```go
// crypto.Signer — v2.6.8 源码实际接口
type Signer interface {
    // Name 返回签名器名称
    Name() string
    // Sign 签名
    Sign(data []byte) ([]byte, error)
    // Verify 验签（v2.6.3 起原独立 Verifier 接口合并进来）
    Verify(data []byte, signature []byte) (bool, error)
}
```

> ⚠️ **v2.6.3 Breaking**: `crypto.RegisterSigner` / `crypto.InvokeSigner` 全局注册/查找函数**已移除**；`crypto.Verifier` 接口也已整体删除，验签能力合并进 `Signer.Verify`。

## 会话安全（握手加密，v2.6.3 新增）

会话安全用于 Gate 与客户端之间的链路加密：客户端发起 X25519 握手，Gate 用签名私钥签署 ServerHello，双方通过 HKDF 派生双向密钥；业务 payload 使用协商出的 AEAD 套件（默认 AES-256-GCM / ChaCha20-Poly1305）加封，并带消息计数与 64-bit 重放窗口。AAD 为 11 字节，绑定协议版本、方向、key epoch、route、seq。消息路径另提供 `SealMessage` / `OpenMessage`，可把密文/明文追加到调用方缓冲并复用池化 nonce/AAD 工作区。

```go
import (
    "github.com/dobyte/due/crypto/rsa/v2"
    "github.com/dobyte/due/network/tcp/v2"
    "github.com/dobyte/due/v2/cluster/client"
    "github.com/dobyte/due/v2/cluster/gate"
)

// Gate：用私钥签名 ServerHello
gateSigner := rsa.NewSigner(rsa.WithSignerPrivateKey("./etc/rsa/private.pem"))

gateComponent := gate.NewGate(
    gate.WithServer(tcp.NewServer()),
    gate.WithSessionSecurity(gateSigner), // suites 省略时使用默认套件
)

// Client：用对应公钥验证 Gate 的签名
clientSigner := rsa.NewSigner(rsa.WithSignerPublicKey("./etc/rsa/public.pem"))

clientComponent := client.NewClient(
    client.WithClient(tcp.NewClient()),
    client.WithSessionSecurity(clientSigner),
)
```

> **注意**：
> - 启用会话安全后，Gate 负责解密上行、重新加封下行，**Node 侧的 `WithEncryptor` 应保持不配置**。
> - 握手超时默认 5s，可用 `gate.WithSessionSecurityHandshakeTimeout` 调整；`0` 表示关闭超时。
> - 需要显式指定套件时传 `aesgcm.Suite` / `chacha20poly1305.Suite`（`core/security/aead/...`）。
> - 旧的 `WithEnableTamperProtection` / `enableTamperProtection` 已移除，不要再配置。

## 在节点服务器中使用加密

```go
package main

import (
    "github.com/dobyte/due/crypto/rsa/v2"
    "github.com/dobyte/due/v2"
    "github.com/dobyte/due/v2/cluster/node"
)

func main() {
    // 创建加密器
    encryptor := rsa.NewEncryptor(
        rsa.WithEncryptorPublicKey("./etc/rsa/public.pem"),
        rsa.WithEncryptorPrivateKey("./etc/rsa/private.pem"),
    )

    // 创建节点组件并配置加密器
    component := node.NewNode(
        node.WithEncryptor(encryptor),
    )

    container := due.NewContainer()
    container.Add(component)
    container.Serve()
}
```

> 说明:`WithEncryptor` 可用于 node、mesh、client 组件,用于加密组件间传输的消息。**启用客户端会话安全时,Node 侧应保持不配置**——Gate 已完成上行解密/下行加封,Node 再配静态加密器会导致解密失败。

## 最佳实践

1. **密钥管理**:
   - 使用安全的密钥存储方案
   - 定期轮换密钥
   - 不要将密钥硬编码在代码中

2. **算法选择**:
   - RSA适用于互操作性要求高、需要广泛兼容的场景
   - ECC适用于密钥更短、计算开销更小的场景
   - 根据安全需求选择合适的密钥长度与曲线

3. **性能优化**:
   - RSA加密速度较慢,适合加密小数据,大数据需分块处理
   - ECIES适合加密任意长度数据,可优先考虑

4. **安全性**:
   - 使用足够长的密钥(RSA建议2048位以上、ECC建议P256及以上)
   - 启用TLS保护传输层
   - 定期更新加密库版本

## 版本更新摘要

### v2.6.8

- 加密/签名包无 API 变化，仅依赖对齐

### v2.6.7

- 会话安全的选项分组内部重构（握手超时归入 `securityOptions`），公开 Option 不变

### v2.6.6 / v2.6.4

- 无 API 或行为变化

### v2.6.5

**性能**：
- RSA 分块加解密循环改用整数 range 语法（行为不变）

### v2.6.3

**Breaking Changes**：
- 会话安全组件从 `crypto/{aead,aesgcm,chacha20poly1305,handshake}` 迁至 `core/security/...`；`WithSessionSecurity(signer crypto.Signer, suites ...aead.Suite)`
- 删除 `crypto.Verifier` 与 `RegisterEncryptor` / `InvokeEncryptor` / `RegisterSigner` / `InvokeSigner`；验签统一走 `Signer.Verify`，`rsa.Verifier` / `ecc.Verifier` 删除
- `WithEnableTamperProtection` / `etc.cluster.{client,node}.enableTamperProtection` / `errors.ErrTamperedMessage` 删除，改用握手会话安全；`WithEncryptor` 只保护 payload
- RSA 加密默认改为 **OAEP**（旧行为需显式 `NORMAL`）；私钥文件权限 0600、ECC 密钥目录 0700

**新特性**：
- 握手会话加密：X25519 + 签名 ServerHello + HKDF 双向密钥 + 64-bit 重放窗口；默认套件 AES-256-GCM / ChaCha20-Poly1305
- Gate 握手状态机与 5s 握手超时（`WithSessionSecurityHandshakeTimeout`）
