# 加密签名 (Crypto)

## 概述

加密签名模块是 Due 框架的核心组件,提供数据加密、解密、签名、验签等安全能力。支持 RSA、ECC(ECIES/ECDSA)等非对称加密算法,保障数据传输安全。

## 包路径

```go
import (
    "github.com/dobyte/due/v2/crypto"       // 加密器/签名器接口与注册中心
    "github.com/dobyte/due/crypto/rsa/v2"   // RSA 实现
    "github.com/dobyte/due/crypto/ecc/v2"   // ECC 实现
)
```

## RSA 加密

### 配置参数

```toml
[crypto.rsa.encryptor]
    # hash算法,不区分大小写。可选:SHA1 | SHA224 | SHA256 | SHA384 | SHA512。默认为SHA256

    publicKey = ""
```

### 使用示例

```go
package main

import (
    "github.com/dobyte/due/crypto/rsa/v2"
)

func main() {
    // 创建RSA加密器(公钥用于加密,私钥用于解密)
    encryptor := rsa.NewEncryptor(
        rsa.WithEncryptorPublicKey("./etc/rsa/public.pem"),
        rsa.WithEncryptorPrivateKey("./etc/rsa/private.pem"),
        rsa.WithEncryptorPadding(rsa.OAEP),
    )

    // 加密数据
    ciphertext, err := encryptor.Encrypt([]byte("hello world"))
    if err != nil {
        panic(err)
    }

    // 解密数据
    plaintext, err := encryptor.Decrypt(ciphertext)
    if err != nil {
        panic(err)
    }

    println(string(plaintext))
}
```

## ECC 加密

ECC 使用 ECIES 加解密、ECDSA 签名验签,基于椭圆曲线,密钥更短。支持 P224、P256、P384、P521 曲线。

### 配置参数

```toml
[crypto.ecc.encryptor]
    # 共享信息,加解密时必需一致
    s1 = ""
    # 共享信息,加解密时必需一致
    s2 = ""
    # 公钥,可设置文件路径或公钥串
    publicKey = ""

[crypto.ecc.decryptor]
    # 共享信息,加解密时必需一致
    s1 = ""
    # 共享信息,加解密时必需一致
    s2 = ""
    # 私钥,可设置文件路径或私钥串
    privateKey = ""

[crypto.ecc.signer]
    # hash算法,不区分大小写。可选:SHA1 | SHA224 | SHA256 | SHA384 | SHA512
    hash = "SHA256"
    # 签名分隔符。ECDSA签名会产生两段签名串,需通过分隔符拼接为一个签名
    delimiter = " "
    # 私钥,可设置文件路径或私钥串
    privateKey = ""

[crypto.ecc.verifier]
    # hash算法,不区分大小写。可选:SHA1 | SHA224 | SHA256 | SHA384 | SHA512
    hash = "SHA256"
    # 签名分隔符
    delimiter = " "
    # 公钥,可设置文件路径或公钥串
    publicKey = ""
```

## 数字签名

### RSA 签名示例

```go
package main

import (
    "github.com/dobyte/due/crypto/rsa/v2"
)

func main() {
    // 创建RSA签名器(私钥用于签名,公钥用于验签)
    signer := rsa.NewSigner(
        rsa.WithSignerPrivateKey("./etc/rsa/private.pem"),
        rsa.WithSignerPublicKey("./etc/rsa/public.pem"),
        rsa.WithSignerPadding(rsa.PSS),
    )

    data := []byte("hello world")

    // 签名
    signature, err := signer.Sign(data)
    if err != nil {
        panic(err)
    }

    // 验签
    valid, err := signer.Verify(data, signature)
    if err != nil {
        panic(err)
    }
    if valid {
        println("Signature is valid")
    } else {
        println("Signature is invalid")
    }
}
```

## 在节点服务器中使用加密

```go
package main

import (
    "github.com/dobyte/due/crypto/rsa/v2"
    "github.com/dobyte/due/v2"
    "github.com/dobyte/due/v2/cluster/node"
)

func main() {
    // 创建加密器
    encryptor := rsa.NewEncryptor(
        rsa.WithEncryptorPublicKey("./etc/rsa/public.pem"),
        rsa.WithEncryptorPrivateKey("./etc/rsa/private.pem"),
    )

    // 创建节点组件并配置加密器
    component := node.NewNode(
        node.WithEncryptor(encryptor),
    )

    container := due.NewContainer()
    container.Add(component)
    container.Serve()
}
```

> 说明:`WithEncryptor` 可用于 node、mesh、client 组件,用于加密组件间传输的消息。

## 最佳实践

1. **密钥管理**:
   - 使用安全的密钥存储方案
   - 定期轮换密钥
   - 不要将密钥硬编码在代码中

2. **算法选择**:
   - RSA适用于互操作性要求高、需要广泛兼容的场景
   - ECC适用于密钥更短、计算开销更小的场景
   - 根据安全需求选择合适的密钥长度与曲线

3. **性能优化**:
   - RSA加密速度较慢,适合加密小数据,大数据需分块处理
   - ECIES适合加密任意长度数据,可优先考虑

4. **安全性**:
   - 使用足够长的密钥(RSA建议2048位以上、ECC建议P256及以上)
   - 启用TLS保护传输层
   - 定期更新加密库版本
