# 配置中心 (Config)

## 概述

配置中心（`config` 包）是 Due 框架的运行时配置组件，提供统一的配置管理能力。支持本地文件（file）与远程配置中心（Consul、Etcd、Nacos、Polaris）等多种配置源，并通过 Watch 监听实现配置的动态更新与热加载。

需要注意与「启动配置」的区分：启动配置由 `etc` 包管理，仅从本地文件（默认 `./etc` 目录）加载，用于集群、服务组件等启动参数，无法动态修改；业务运行时配置推荐使用 `config` 配置中心，可在运行时动态修改并热更新。

> **v2.6.8 变更**：config 核心实现从顶层 `config` 包重构到 `core/config`，公共 API facade 保持不变；所有 config source 均新增 `files` 选项支持精确文件列表与 `*` 通配符过滤；配置可靠性增强（source 启动失败后台重试、watcher 指数退避重连、回调 panic 隔离）。详见文末「版本更新摘要」。

## 本地文件配置

### 配置文件格式

Due 框架默认支持以下配置文件格式（由默认编解码器解析）：
- TOML (.toml)
- JSON (.json)
- YAML (.yaml, .yml)
- XML (.xml)

### 配置示例

本地文件配置源默认加载 `./config` 目录（或由 `path` 指定的文件/目录），每个配置文件以其文件名（不含扩展名）作为顶层命名空间。

```toml
# 文件名为 config.toml，其顶层键以文件名 config 作为命名空间
# 例如下方 timezone 通过 config.Get("config.timezone") 读取

# 统一时区设置
timezone = "Local"

[cluster.node]
    # 实例名称
    name = "node"
    # 监听地址
    addr = ":0"
```

### files 选项（v2.6.8 新增）

从 v2.6.8 开始，所有 config source 均支持 `files` 选项，用于限制 Load、Store 和 Watch 仅作用于指定文件列表。`files` 列表中的每个条目可以是：

- **精确文件名**：如 `"game.toml"`，只匹配该文件
- **`*` 通配符模式**：如 `"*.toml"` 匹配所有 TOML 文件，`"shop-*"` 匹配所有以 `shop-` 开头的文件

```go
// 示例：仅加载 game.toml 和所有以 shop- 开头的 TOML 文件
import (
    "github.com/dobyte/due/v2/config"
    "github.com/dobyte/due/v2/config/file"
)

source := file.NewSource(
    file.WithPath("./config"),
    file.WithFiles([]string{"game.toml", "shop-*.toml"}),
)
config.SetConfiguratorWithSources(source)
```

> **注意**：显式调用 `config.Load(ctx, source, "未配置的文件")` 或 `config.Store(ctx, source, "未配置的文件", content)` 时，如果文件名不在 `files` 列表中，会返回 `errors.ErrFileNotConfigured` 错误。目录加载和 Watch 事件会自动过滤未列出的文件。

## 核心 API

### 配置读取

```go
package config

// 创建配置器（可选配置项：WithSources 配置源、WithContext 等）
func NewConfigurator(opts ...Option) Configurator

// 设置全局配置器
func SetConfigurator(configurator Configurator)

// 由配置源创建并设置全局配置器
func SetConfiguratorWithSources(sources ...Source)

// 获取全局配置器
func GetConfigurator() Configurator

// 检查配置是否存在
func Has(pattern string) bool

// 获取配置值，缺失时返回默认值
func Get(pattern string, def ...any) value.Value

// 设置配置值
func Set(pattern string, value any) error

// 按顺序匹配多个 pattern 并返回匹配器
func Match(patterns ...string) Matcher

// 监听配置变更，names 为空表示监听所有配置
func Watch(cb WatchCallbackFunc, names ...string)

// 加载指定配置源的配置
func Load(ctx context.Context, source string, file ...string) ([]*Configuration, error)

// 保存配置到指定配置源
func Store(ctx context.Context, source string, file string, content any, override ...bool) error

// 关闭全局配置器
func Close()
```

> **v2.6.8 行为说明**：
> - `Get` 和 `Matcher.Get` 返回的值可能引用内部 map/slice，调用方应视为只读
> - `Set` 的 slice 扩展上限为 10000，防止超大索引导致内存溢出
> - 多个 source 时，后加载的 source 会 merge 而非覆盖已存在的配置值（Set 操作整体替换标量值）
> - Watch 回调会被序列化执行，并隔离 panic，单个回调异常不影响其他回调

### Value 接口

```go
type Value interface {
    // 基础类型转换
    Int() int
    Int8() int8
    Int16() int16
    Int32() int32
    Int64() int64
    Uint() uint
    Uint64() uint64
    Float32() float32
    Float64() float64
    Bool() bool
    String() string
    Duration() time.Duration
    // 切片类型转换
    Ints() []int
    Int64s() []int64
    Strings() []string
    Bytes() []byte
    Slice() []any
    // 映射与结构扫描
    Map() map[string]any
    Scan(pointer any) error
    // 原始值与类型判断
    Value() any
    Kind() reflect.Kind
    IsMap() bool
    IsSlice() bool
    IsStruct() bool
}
```

### Value.Scan 增强（v2.6.8）

Scan 方法在 v2.6.8 进行了重写，支持：

- **struct default 标签**：当配置缺失时，使用结构体字段的 `default` 标签值填充
- **跨类型转换**：兼容标量、struct、map、slice、array 之间的类型转换
- **json 单字节扫描解码**：直接从 JSON 字节流解码，减少中间 map 构建
- **零分配优化**：减少 interface boxing 和 per-field 路径构建

```go
type GameConfig struct {
    MaxLevel    int     `json:"maxLevel" default:"100"`
    ExpRate     float64 `json:"expRate" default:"1.0"`
    DropRate    float64 `json:"dropRate" default:"1.0"`
    Debug       bool    `json:"debug" default:"false"`
}

var cfg GameConfig
// 如果 config.game 缺失部分字段，缺失字段将使用 default 标签值填充
if err := config.Get("game").Scan(&cfg); err != nil {
    log.Errorf("读取游戏配置失败: %v", err)
}
```

## 使用场景示例

### 基础使用

```go
package main

import (
    "github.com/dobyte/due/v2/config"
)

func main() {
    // 读取字符串配置（config 为配置文件名命名空间）
    name := config.Get("config.cluster.node.name").String()
    println("Node name:", name)
    
    // 读取整数配置，缺失时返回默认值
    port := config.Get("config.cluster.node.port", 8080).Int()
    println("Port:", port)
    
    // 读取布尔配置
    debug := config.Get("config.debug", false).Bool()
    println("Debug mode:", debug)
    
    // 读取时间配置
    timeout := config.Get("config.timeout", "5s").Duration()
    println("Timeout:", timeout)
    
    // 检查配置是否存在
    if config.Has("config.cluster.node.id") {
        id := config.Get("config.cluster.node.id").String()
        println("Node ID:", id)
    }
}
```

### 嵌套配置读取

```go
package main

import (
    "github.com/dobyte/due/v2/config"
)

func main() {
    // 读取字符串切片配置
    addrs := config.Get("config.locate.redis.addrs").Strings()
    for _, addr := range addrs {
        println("Redis address:", addr)
    }
    
    // 读取 map 配置
    metadata := config.Get("config.cluster.node.metadata").Map()
    for k, v := range metadata {
        println(k, ":", v)
    }
}
```

### 动态配置更新

```go
package main

import (
    "github.com/dobyte/due/v2/config"
)

func main() {
    // 设置配置值
    if err := config.Set("config.cluster.node.name", "node-1"); err != nil {
        panic(err)
    }
    
    // 读取更新后的配置
    name := config.Get("config.cluster.node.name").String()
    println("Updated node name:", name)
    
    // 监听配置变更，实现热更新
    config.Watch(func(names ...string) {
        println("config changed:", names)
    }, "config")
}
```

## 环境变量配置

### 使用示例

```go
package main

import (
    "github.com/dobyte/due/v2/env"
)

func main() {
    // 启动配置（etc）默认读取 ./etc 目录，可通过环境变量 DUE_ETC 指定路径，

    println("Etc path:", path)
}
```

## 远程配置中心

### Consul 配置中心

```toml
[config.consul]
    # 客户端连接地址
    addr = "127.0.0.1:8500"
    # 配置路径。默认为config
    path = "config"
    # 读写模式。可选：read-only | write-only | read-write，默认为read-only
    mode = "read-only"
    # 文件过滤列表（v2.6.8 新增）。支持精确文件名和 "*" 通配符
    files = ["game.toml", "shop-*.toml"]
```

```go
package main

import (
    "github.com/dobyte/due/config/consul/v2"
    "github.com/dobyte/due/v2/config"
)

func main() {
    // 由配置源创建并设置全局配置器（内部自动启动 Watch 监听，实现热更新）
    config.SetConfiguratorWithSources(consul.NewSource())

    // 读取配置（config 对应配置文件命名空间）
    timezone := config.Get("config.timezone").String()
    println("Timezone:", timezone)
}
```

> **v2.6.8 Breaking Change**：`consul.WithContext` 选项已移除。Configurator 现在通过 `Source.Load` 和 `Source.Watch` 传递 context，不再需要手动指定。

### Nacos 配置中心

```toml
[config.nacos]
    # 读写模式。可选：read-only | write-only | read-write，默认为read-only
    mode = "read-only"
    # 服务器地址 [scheme://]ip:port[/nacos]，默认为["http://127.0.0.1:8848/nacos"]
    urls = ["http://127.0.0.1:8848/nacos"]
    # 集群名称。默认为DEFAULT
    clusterName = "DEFAULT"
    # 群组名称。默认为DEFAULT_GROUP
    groupName = "DEFAULT_GROUP"
    # 请求Nacos服务端超时时间，默认为3s
    timeout = "3s"
    # ACM的命名空间Id。默认为空
    namespaceId = ""
    # 用户名（v2.6.8 新增：支持服务端 API 鉴权）
    username = ""
    # 密码（v2.6.8 新增：支持服务端 API 鉴权）
    password = ""
    # 文件过滤列表（v2.6.8 新增）。包含 "*" 的条目会作为模糊模式匹配
    files = ["game.toml", "shop-*", "*.toml"]
```

```go
package main

import (
    "github.com/dobyte/due/config/nacos/v2"
    "github.com/dobyte/due/v2/config"
)

func main() {
    // 由配置源创建并设置全局配置器（内部自动启动 Watch 监听，实现热更新）
    config.SetConfiguratorWithSources(nacos.NewSource())

    // 读取配置（dataId 即配置文件命名空间，如 due.toml 对应 due）
    timezone := config.Get("due.timezone").String()
    println("Timezone:", timezone)
}
```

> **v2.6.8 Nacos 嵌套 key Breaking Change**：
> 从 v2.6.8 开始，Nacos/Polaris 中位于嵌套 dataId 下的配置（如 `path/to/game.toml`），将按 **basename**（`game`）作为 config key，而非完整 dataId 路径。因此 `config.Get("game.xxx")` 可以读取 `path/to/game.toml`，但需避免不同路径下出现相同 basename 的文件。

> **v2.6.8 Nacos 延迟登录**：客户端登录改为首次请求时延迟执行，不再阻塞构造函数调用。

## 错误类型

框架使用统一的 errors 包定义导出错误：

```go
import "github.com/dobyte/due/v2/errors"

// config.Source.Load / Store 操作的常见错误
errors.ErrFileNotConfigured    // 显式 Load / Store 操作的文件名不在配置源的 files 列表中
errors.ErrConfigAuthRequired   // Nacos 等远程配置中心需要鉴权但未提供凭证
```

## 最佳实践

1. **配置分层**:
   - 使用点号分隔的 key 组织配置结构，顶层以配置文件名（或 dataId）作为命名空间
   - 例如：`config.toml` 中的 `cluster.node.name` 通过 `config.Get("config.cluster.node.name")` 读取

2. **默认值**:
   - 为重要配置设置合理的默认值
   - 使用 `config.Get(pattern, defaultValue)` 提供默认值
   - v2.6.8 起，struct Scan 支持 `default` 标签

3. **配置验证**:
   - 在启动时通过 `config.Has(pattern)` 验证必要配置是否存在
   - 检查配置值的合法性

4. **热更新**:
   - 使用远程配置中心实现配置热更新
   - 通过 `config.Watch(cb, names...)` 监听配置变更并及时响应
   - v2.6.8 起，启动失败的 source 会自动后台重试，Watch 回调 panic 不会中断进程

5. **安全性**:
   - 敏感配置使用环境变量或密钥管理服务
   - 不要将密码等敏感信息硬编码在配置文件中

6. **files 过滤（v2.6.8 推荐）**:
   - 在远程配置中心中使用 `files` 选项限制加载范围，减少网络开销和内存占用
   - 模式匹配自动利用 Nacos 服务端 blur 关键字优化，无需额外配置

## 版本更新摘要

### v2.6.8

**Breaking Changes**:
- `core/pattern` 通配符辅助函数移至 `core/config`，直接依赖该包的代码需更新 import 路径
- `consul.WithContext` 选项已移除（context 由 configurator 自动传递）
- Nacos/Polaris 嵌套 dataId 的配置按 basename 作为 key（如 `path/to/game.toml` → `game`），避免跨路径重名

**新特性**:
- 所有 config source 新增 `files` 选项，支持精确文件名 + `*` 通配符过滤
- Nacos files 列表中的通配符自动使用服务端 blur 关键字优化模糊查询
- 配置源启动失败时在后台自动重试并合并配置
- Watcher 异常停止后以有上限的指数退避自动重连
- Watch 回调隔离 panic 并序列化执行，单个回调异常不影响其他回调
- 只发布实际变更的配置值，避免无效通知
- Value.Scan 重写：支持 struct `default` 标签、跨类型转换、零分配 JSON 解码
- 新增 `errors.ErrFileNotConfigured`、`errors.ErrConfigAuthRequired` 导出错误
- Etcd 新增 `watchTimeout` 配置项
- Polaris config 新增 `cacheDir`、`logDir` 配置项，升级 polaris-go 到 v1.7.2
