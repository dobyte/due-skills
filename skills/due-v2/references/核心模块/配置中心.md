# 配置中心 (Config)

## 概述

配置中心（`config` 包）是 Due 框架的运行时配置组件，提供统一的配置管理能力。支持本地文件（file）与远程配置中心（Consul、Etcd、Nacos、Polaris）等多种配置源，并通过 Watch 监听实现配置的动态更新与热加载。

需要注意与「启动配置」的区分：启动配置由 `etc` 包管理，仅从本地文件（默认 `./etc` 目录）加载，用于集群、服务组件等启动参数，无法动态修改；业务运行时配置推荐使用 `config` 配置中心，可在运行时动态修改并热更新。

## 包路径

```go
import "github.com/dobyte/due/v2/config"

// 本地文件配置源（随框架主模块发布）
import "github.com/dobyte/due/v2/config/file"

// 远程配置中心为独立子模块
import (
    "github.com/dobyte/due/config/consul/v2"
    "github.com/dobyte/due/config/etcd/v2"
    "github.com/dobyte/due/config/nacos/v2"
    "github.com/dobyte/due/config/polaris/v2"
)
```

## 本地文件配置

### 配置文件格式

Due 框架默认支持以下配置文件格式（由默认编解码器解析）：
- TOML (.toml)
- JSON (.json)
- YAML (.yaml, .yml)
- XML (.xml)

### 配置示例

本地文件配置源默认加载 `./config` 目录（或由 `path` 指定的文件/目录），每个配置文件以其文件名（不含扩展名）作为顶层命名空间。

```toml
# 文件名为 config.toml，其顶层键以文件名 config 作为命名空间
# 例如下方 timezone 通过 config.Get("config.timezone") 读取

# 统一时区设置
timezone = "Local"

[cluster.node]
    # 实例名称
    name = "node"
    # 监听地址
    addr = ":0"
```

## 核心 API

### 配置读取

```go
package config

// 创建配置器（可选配置项：WithSources 配置源、WithContext 等）
func NewConfigurator(opts ...Option) Configurator

// 设置全局配置器
func SetConfigurator(configurator Configurator)

// 由配置源创建并设置全局配置器
func SetConfiguratorWithSources(sources ...Source)

// 获取全局配置器
func GetConfigurator() Configurator

// 检查配置是否存在
func Has(pattern string) bool

// 获取配置值，缺失时返回默认值
func Get(pattern string, def ...any) value.Value

// 设置配置值
func Set(pattern string, value any) error

// 按顺序匹配多个 pattern 并返回匹配器
func Match(patterns ...string) Matcher

// 监听配置变更，names 为空表示监听所有配置
func Watch(cb WatchCallbackFunc, names ...string)

// 加载指定配置源的配置
func Load(ctx context.Context, source string, file ...string) ([]*Configuration, error)

// 保存配置到指定配置源
func Store(ctx context.Context, source string, file string, content any, override ...bool) error

// 关闭全局配置器
func Close()
```

## 使用场景示例

### 基础使用

```go
package main

import (
    "github.com/dobyte/due/v2/config"
)

func main() {
    // 读取字符串配置（config 为配置文件名命名空间）
    name := config.Get("config.cluster.node.name").String()
    println("Node name:", name)
    
    // 读取整数配置，缺失时返回默认值
    port := config.Get("config.cluster.node.port", 8080).Int()
    println("Port:", port)
    
    // 读取布尔配置
    debug := config.Get("config.debug", false).Bool()
    println("Debug mode:", debug)
    
    // 读取时间配置
    timeout := config.Get("config.timeout", "5s").Duration()
    println("Timeout:", timeout)
    
    // 检查配置是否存在
    if config.Has("config.cluster.node.id") {
        id := config.Get("config.cluster.node.id").String()
        println("Node ID:", id)
    }
}
```

### 嵌套配置读取

```go
package main

import (
    "github.com/dobyte/due/v2/config"
)

func main() {
    // 读取字符串切片配置
    addrs := config.Get("config.locate.redis.addrs").Strings()
    for _, addr := range addrs {
        println("Redis address:", addr)
    }
    
    // 读取 map 配置
    metadata := config.Get("config.cluster.node.metadata").Map()
    for k, v := range metadata {
        println(k, ":", v)
    }
}
```

### 动态配置更新

```go
package main

import (
    "github.com/dobyte/due/v2/config"
)

func main() {
    // 设置配置值
    if err := config.Set("config.cluster.node.name", "node-1"); err != nil {
        panic(err)
    }
    
    // 读取更新后的配置
    name := config.Get("config.cluster.node.name").String()
    println("Updated node name:", name)
    
    // 监听配置变更，实现热更新
    config.Watch(func(names ...string) {
        println("config changed:", names)
    }, "config")
}
```

## 环境变量配置

### 使用示例

```go
package main

import (
    "github.com/dobyte/due/v2/env"
)

func main() {
    // 启动配置（etc）默认读取 ./etc 目录，可通过环境变量 DUE_ETC 指定路径，
    // 也可由运行参数 --etc 覆盖（优先级：默认值 < 环境变量 < 运行参数）
    path := env.Get("DUE_ETC", "./etc").String()
    println("Etc path:", path)
}
```

## 远程配置中心

### Consul 配置中心

```toml
[config.consul]
    # 客户端连接地址
    addr = "127.0.0.1:8500"
    # 配置路径。默认为config
    path = "config"
    # 读写模式。可选：read-only | write-only | read-write，默认为read-only
    mode = "read-only"
```

```go
package main

import (
    "github.com/dobyte/due/config/consul/v2"
    "github.com/dobyte/due/v2/config"
)

func main() {
    // 由配置源创建并设置全局配置器（内部自动启动 Watch 监听，实现热更新）
    config.SetConfiguratorWithSources(consul.NewSource())

    // 读取配置（config 对应配置文件命名空间）
    timezone := config.Get("config.timezone").String()
    println("Timezone:", timezone)
}
```

### Nacos 配置中心

```toml
[config.nacos]
    # 读写模式。可选：read-only | write-only | read-write，默认为read-only
    mode = "read-only"
    # 服务器地址 [scheme://]ip:port[/nacos]，默认为["http://127.0.0.1:8848/nacos"]
    urls = ["http://127.0.0.1:8848/nacos"]
    # 集群名称。默认为DEFAULT
    clusterName = "DEFAULT"
    # 群组名称。默认为DEFAULT_GROUP
    groupName = "DEFAULT_GROUP"
    # 请求Nacos服务端超时时间，默认为3s
    timeout = "3s"
    # ACM的命名空间Id。默认为空
    namespaceId = ""
```

```go
package main

import (
    "github.com/dobyte/due/config/nacos/v2"
    "github.com/dobyte/due/v2/config"
)

func main() {
    // 由配置源创建并设置全局配置器（内部自动启动 Watch 监听，实现热更新）
    config.SetConfiguratorWithSources(nacos.NewSource())

    // 读取配置（dataId 即配置文件命名空间，如 due.toml 对应 due）

    println("Timezone:", timezone)
}
```

## 最佳实践

1. **配置分层**:
   - 使用点号分隔的 key 组织配置结构，顶层以配置文件名（或 dataId）作为命名空间
   - 例如：`config.toml` 中的 `cluster.node.name` 通过 `config.Get("config.cluster.node.name")` 读取

2. **默认值**:
   - 为重要配置设置合理的默认值
   - 使用 `config.Get(pattern, defaultValue)` 提供默认值

3. **配置验证**:
   - 在启动时通过 `config.Has(pattern)` 验证必要配置是否存在
   - 检查配置值的合法性

4. **热更新**:
   - 使用远程配置中心实现配置热更新
   - 通过 `config.Watch(cb, names...)` 监听配置变更并及时响应

5. **安全性**:
   - 敏感配置使用环境变量或密钥管理服务
   - 不要将密码等敏感信息硬编码在配置文件中
