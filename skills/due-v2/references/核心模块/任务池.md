# 任务池 (Task)

## 概述

任务池是 Due 框架的全局任务调度模块，基于 [panjf2000/ants](https://github.com/panjf2000/ants) 协程池实现，提供并发控制、错误聚合与优雅降级能力。框架容器关闭时会自动释放全局任务池。

任务池在包初始化时自动创建全局实例，业务代码无需手动初始化即可直接使用。

## 包路径

```go
import "github.com/dobyte/due/v2/task"
```

## 配置参数

在 `etc.toml` 配置文件中配置任务池参数：

```toml
[task]
    # 任务池大小(goroutine)，默认为100000
    size = 100000
    # 是否非阻塞，默认为true。非阻塞模式下，任务池已满时提交任务会立即返回错误而非阻塞等待
    nonblocking = true
    # 是否禁用清除，默认为true。禁用后空闲协程不会被定期回收
    disablePurge = true
```

## 核心 API

### 全局任务池

```go
// Add 提交任务到全局任务池。
// 任务池已满或不可用时，自动降级为直接创建协程执行该任务，并输出警告日志
func Add(task func())

// AddTask 提交任务到全局任务池。
// Deprecated: 自 due v2.6.0+ 起，该函数等价于 Add，建议使用 Add
func AddTask(task func())

// Release 释放全局任务池
func Release()
```

### 独立任务池

```go
// Pool 任务池接口
type Pool interface {
    // AddTask 添加任务到任务池并返回错误
    AddTask(task func()) error
    // Release 释放任务池
    Release()
}

// NewPool 创建新的任务池（不读写全局状态，可创建多个独立实例）
func NewPool(opts ...Option) *defaultPool

// SetPool 设置全局任务池（会先释放旧的全局池）
func SetPool(pool Pool)

// GetPool 获取全局任务池
func GetPool() Pool
```

### 池选项

```go
// WithSize 设置任务池大小（goroutine数量）
func WithSize(size int) Option

// WithNonblocking 设置是否非阻塞。
// 非阻塞模式下，任务池已满时任务提交会立即返回错误而非阻塞等待
func WithNonblocking(nonblocking bool) Option

// WithDisablePurge 设置是否禁用清除。
// 禁用后空闲协程不会被定期回收
func WithDisablePurge(disablePurge bool) Option
```

### 任务组 (ErrGroup)

```go
// WithContext 创建任务组，返回任务组与派生的 context。
// 第一个任务失败（或 Wait 返回）时，派生的 context 会被取消，并以首个错误为取消原因
func WithContext(ctx context.Context) (*Group, context.Context)
```

| 方法 | 说明 |
|------|------|
| `g.Go(f func() error)` | 提交任务到全局任务池执行；任务出错时记录首个错误并取消派生 context |
| `g.TryGo(f func() error) bool` | 尝试提交任务；未达并发上限时启动任务并返回 true，否则返回 false |
| `g.SetLimit(n int)` | 设置并发上限；n 为负数表示不限制，必须在任务启动前设置，运行中修改会 panic |
| `g.Wait() error` | 阻塞等待全部任务完成并取消派生 context，返回首个失败任务的错误（无失败返回 nil） |

## 使用示例

### 提交任务到全局池

```go
package main

import "github.com/dobyte/due/v2/task"

func main() {
    // 提交异步任务（池满时自动降级为直接开协程执行）
    task.Add(func() {
        // 耗时操作，如数据落盘、统计上报等
    })
}
```

### 创建独立任务池

```go
package main

import "github.com/dobyte/due/v2/task"

func main() {
    pool := task.NewPool(
        task.WithSize(1000),
        task.WithNonblocking(true),
        task.WithDisablePurge(false),
    )
    defer pool.Release()

    if err := pool.AddTask(func() {
        // 业务逻辑
    }); err != nil {
        // 非阻塞模式下池满会返回错误
    }
}
```

### 任务组：并发控制与错误聚合

```go
package main

import (
    "context"

    "github.com/dobyte/due/v2/task"
)

func main() {
    g, ctx := task.WithContext(context.Background())
    // 最多 10 个任务并发执行
    g.SetLimit(10)

    for i := 0; i < 100; i++ {
        g.Go(func() error {
            select {
            case <-ctx.Done():
                // 首个任务出错后，后续任务可通过 ctx 感知取消
                return ctx.Err()
            default:
            }
            return doWork()
        })
    }

    if err := g.Wait(); err != nil {
        // err 为首个失败任务的错误
    }
}
```

## 注意事项

1. **降级语义**：全局池的 `Add` 在池满（非阻塞）或池不可用时**不会丢弃任务**，而是降级为直接创建协程执行并输出警告日志；独立池的 `Pool.AddTask` 则直接返回错误，由调用方决定处理方式。
2. **任务组复用全局池**：`Group.Go/TryGo` 的任务跑在全局任务池上，受全局池的 size/nonblocking 配置约束。
3. **SetLimit 时机**：必须在任何任务启动前调用，运行中修改会 panic；负数表示不限制。
4. **资源释放**：容器 `Serve` 退出时会自动 `task.Release()`；仅在自建独立池或替换全局池时需自行负责释放。
