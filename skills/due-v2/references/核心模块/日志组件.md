# 日志组件 (Log)

## 概述

日志组件是 Due 框架的核心模块之一，提供结构化、高性能的日志记录功能。支持多种日志级别、自定义格式化、文件轮转等特性。

## 包路径

```go
import "github.com/dobyte/due/v2/log"
```

## 日志级别

Due 框架支持以下日志级别（按优先级从低到高）：

- `LevelDebug` - 调试级别，用于开发调试信息
- `LevelInfo` - 信息级别，用于一般信息记录
- `LevelWarn` - 警告级别，用于潜在问题提示
- `LevelError` - 错误级别，用于错误信息记录
- `LevelFatal` - 致命级别，记录后程序会退出
- `LevelPanic` - 恐慌级别，记录后程序会 panic

此外还有 `LevelNone`，用于表示不输出任何级别的日志。

## 配置参数

在 `etc.toml` 配置文件中配置日志参数：

```toml
[log]
    # 日志输出级别，可选：debug | info | warn | error | fatal | panic
    level = "info"
    # 堆栈的最低输出级别，可选：debug | info | warn | error | fatal | panic
    stackLevel = "error"
    # 时间格式，标准库时间格式
    timeFormat = "2006/01/02 15:04:05.000000"
    # 输出栈的跳过深度
    callSkip = 2
    # 是否启用调用文件全路径
    callFullPath = true
    # 日志输出终端，两种形式二选一：
    #   1) 数组形式：terminals = ["console", "file"]
    #   2) 对象形式（如下，逐终端指定级别）
    [log.terminals]
        # 控制台 -> 日志级别
        console = ["debug", "info", "warn", "error", "fatal", "panic"]
        # 文件 -> 日志级别
        file = ["debug", "info", "warn", "error", "fatal", "panic"]
        # 阿里云日志 -> 日志级别
        aliyun = ["debug", "info", "warn", "error", "fatal", "panic"]
        # 腾讯云日志 -> 日志级别
        tencent = ["debug", "info", "warn", "error", "fatal", "panic"]
    
    # 控制台同步器配置
    [log.console]
        # 日志输出格式，可选：text | json
        format = "text"
    
    # 文件同步器配置
    [log.file]
        # 输出文件路径
        path = "./log/due.log"
        # 日志输出格式，可选：text | json
        format = "text"
        # 文件最大留存时间，d:天、h:时、m:分、s:秒
        maxAge = "7d"
        # 文件最大尺寸限制，支持单位： B | K | KB | M | MB | G | GB | T | TB | P | PB | E | EB | Z | ZB，默认为500M
        maxSize = "500M"
        # 缓冲区大小，支持单位： B | K | KB | M | MB | G | GB | T | TB | P | PB | E | EB | Z | ZB，默认为32K
        bufferSize = "32K"
        # 文件缓冲刷新间隔；<=0 时每条日志立即刷新，>0 时按间隔批量刷新，默认为1s
        flushInterval = "1s"
        # 文件翻转方式，可选：none | year | month | week | day | hour，默认为none
        rotate = "none"
        # 文件翻转时是否对文件进行压缩
        compress = false
    
    # 阿里云SLS日志同步器配置
    [log.aliyun]
        # 服务域名，公网使用公网域名，内网使用私网域名
        endpoint = "cn-chengdu.log.aliyuncs.com"
        # 访问密钥ID
        accessKeyID = ""
        # 访问密钥密码
        accessKeySecret = ""
        # 项目名称
        project = "due-test"
        # 日志存储
        logstore = "app"
        # 主题标签，默认为空
        topic = ""
        # 来源标签，默认为空
        source = ""
    
    # 腾讯云CLS日志服务同步器
    [log.tencent]
        # 服务域名，公网使用公网域名，内网使用私网域名
        endpoint = "ap-guangzhou.cls.tencentcs.com"
        # 访问密钥ID
        accessKeyID = ""
        # 访问密钥密码
        accessKeySecret = ""
        # 主题ID
        topicID = ""
```

## 核心 API

### 基础日志函数

```go
// Print 记录指定级别的日志（不包含堆栈信息）
func Print(level Level, a ...any)

// Debug 记录调试日志
func Debug(a ...any)

// Info 记录信息日志
func Info(a ...any)

// Warn 记录警告日志
func Warn(a ...any)

// Error 记录错误日志
func Error(a ...any)

// Fatal 记录致命错误日志并退出程序
func Fatal(a ...any)

// Panic 记录恐慌日志并 panic
func Panic(a ...any)
```

### 格式化日志函数

```go
// Printf 记录指定级别的格式化日志（不包含堆栈信息）
func Printf(level Level, format string, a ...any)

// Debugf 记录格式化的调试日志
func Debugf(format string, a ...any)

// Infof 记录格式化的信息日志
func Infof(format string, a ...any)

// Warnf 记录格式化的警告日志
func Warnf(format string, a ...any)

// Errorf 记录格式化的错误日志
func Errorf(format string, a ...any)

// Fatalf 记录格式化的致命错误日志并退出程序
func Fatalf(format string, a ...any)

// Panicf 记录格式化的恐慌日志并 panic
func Panicf(format string, a ...any)
```

### 全局函数

```go
// SetLogger 设置全局日志实例
func SetLogger(logger Logger)

// GetLogger 获取全局日志实例
func GetLogger() Logger

// Close 关闭全局日志实例
func Close()
```

## 使用示例

### 基础使用

```go
package main

import "github.com/dobyte/due/v2/log"

func main() {
    // 基础日志
    log.Debug("debug message")
    log.Info("info message")
    log.Warn("warn message")
    log.Error("error message")
    
    // 格式化日志
    log.Infof("user %s logged in", "admin")
    log.Errorf("failed to connect: %v", err)
    
    // 指定级别的日志
    log.Print(log.LevelInfo, "custom level message")
    log.Printf(log.LevelError, "custom level message: %v", err)
    
    // 带错误的日志
    if err := doSomething(); err != nil {
        log.Errorf("operation failed: %v", err)
    }
}
```

### 自定义日志实例

```go
package main

import "github.com/dobyte/due/v2/log"

func main() {
    // 创建自定义日志实例
    logger := log.NewLogger(
        log.WithLevel(log.LevelDebug),
        log.WithCallSkip(1),
    )
    
    logger.Info("custom logger message")
}
```

## 最佳实践

1. **选择合适的日志级别**：
   - 开发调试信息使用 `Debug`
   - 一般业务信息使用 `Info`
   - 潜在问题使用 `Warn`
   - 错误情况使用 `Error`

2. **日志内容**：
   - 记录关键上下文信息，避免在日志消息中大量拼接变量
   - `Logger` 实现了 `slog.Handler`，可与标准库 `log/slog` 集成使用

3. **生产环境配置**：
   - 设置合适的日志级别（建议 `info` 或 `warn`）
   - 启用文件输出并配置轮转策略
   - 设置 `callFullPath = false` 减少日志体积

4. **性能优化**：
   - 通过 `flushInterval` 控制文件写入的批量刷新
   - 避免在循环中记录大量日志
   - 使用 `JSON` 格式便于日志收集和分析
