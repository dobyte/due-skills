# 用户定位 (Locate)

## 概述

用户定位模块是 Due 框架的核心组件,提供分布式环境下的用户位置追踪能力。支持 Redis 存储后端,用于追踪用户当前所在的网关(Gate)与节点(Node)。

## 包路径

```go
import "github.com/dobyte/due/locate/redis/v2"
```

## Redis 定位器

### 配置参数

```toml
[locate.redis]
    # 客户端连接地址
    addrs = ["127.0.0.1:6379"]
    # 数据库号
    db = 0
    # 用户名
    username = ""
    # 密码
    password = ""
    # 私钥文件
    keyFile = ""
    # 证书文件
    certFile = ""
    # CA证书文件
    caFile = ""
    # 最大重试次数
    maxRetries = 3
    # key前缀
    prefix = "due:locate"
```

### 使用示例

```go
package main

import (
    "github.com/dobyte/due/locate/redis/v2"
    "github.com/dobyte/due/v2/cluster/node"
)

func main() {
    // 创建用户定位器
    locator := redis.NewLocator()
    // 创建节点组件
    component := node.NewNode(
        node.WithLocator(locator),
    )
    // ...
}
```

## 核心 API

### 定位器接口

```go
type Locator interface {
    // 返回定位器组件名称
    Name() string
    // 监听用户位置变化,可按类型(kinds)过滤
    Watch(ctx context.Context, kinds ...string) (Watcher, error)
    // 将用户绑定到指定网关(gid)
    BindGate(ctx context.Context, uid int64, gid string) error
    // 将用户绑定到指定节点(name 与 nid)
    BindNode(ctx context.Context, uid int64, name, nid string) error
    // 将用户从指定网关解绑
    UnbindGate(ctx context.Context, uid int64, gid string) error
    // 将用户从指定节点解绑
    UnbindNode(ctx context.Context, uid int64, name string, nid string) error
    // 定位用户所在的网关
    LocateGate(ctx context.Context, uid int64) (string, error)
    // 定位用户在指定名称下所在的节点
    LocateNode(ctx context.Context, uid int64, name string) (string, error)
    // 定位用户绑定的所有节点
    LocateNodes(ctx context.Context, uid int64) (map[string]string, error)
    // 关闭定位器
    Close() error
}
```

### 事件与监听器

```go
type Watcher interface {
    // 获取下一批用户位置事件
    Next() ([]*Event, error)
    // 停止监听
    Stop() error
}

type Event struct {
    UID     int64     // 用户ID
    Type    EventType // 事件类型
    InsID   string    // 实例ID
    InsKind string    // 实例类型
    InsName string    // 实例名称
}

// 事件类型
const (
    BindGate   EventType = iota + 1 // 用户绑定到网关
    BindNode                        // 用户绑定到节点
    UnbindGate                      // 用户从网关解绑
    UnbindNode                      // 用户从节点解绑
)
```

## 使用场景示例

```go
package main

import (
    "context"
    "github.com/dobyte/due/locate/redis/v2"
)

func main() {
    // 创建定位器
    locator := redis.NewLocator()

    ctx := context.Background()

    // 用户登录时绑定到当前网关
    err := locator.BindGate(ctx, 1001, "gate-1")
    if err != nil {
        panic(err)
    }

    // 用户进入节点时绑定到当前节点
    err = locator.BindNode(ctx, 1001, "node", "node-1")
    if err != nil {
        panic(err)
    }

    // 查找用户所在网关
    gate, err := locator.LocateGate(ctx, 1001)
    if err != nil {
        panic(err)
    }
    println("User located at gate:", gate)

    // 查找用户在指定名称下所在节点
    node, err := locator.LocateNode(ctx, 1001, "node")
    if err != nil {
        panic(err)
    }
    println("User located at node:", node)

    // 用户登出时解绑
    if err = locator.UnbindNode(ctx, 1001, "node", "node-1"); err != nil {
        panic(err)
    }
    if err = locator.UnbindGate(ctx, 1001, "gate-1"); err != nil {
        panic(err)
    }
}
```

## 最佳实践

1. **Key前缀**:
   - 使用清晰的key前缀避免冲突
   - 默认前缀为 `due:locate`

2. **连接配置**:
   - 通过 `addrs`、`db`、`username`、`password` 配置连接,多实例可通过 `WithAddrs` 传入
   - 通过 `WithCredentials(certFile, keyFile, caFile)` 启用 TLS 连接

3. **重试机制**:
   - 通过 `maxRetries` 设置客户端最大重试次数,默认为3

4. **清理策略**:
   - 用户登出时及时调用 `UnbindGate`/`UnbindNode` 解绑
   - 通过 `Watch` 监听 `BindGate`/`BindNode`/`UnbindGate`/`UnbindNode` 事件,联动处理会话迁移
