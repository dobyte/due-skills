# 网络通信 (Network)

## 概述

网络通信模块是 Due 框架的核心组件,提供高性能的 TCP、WebSocket、KCP、QUIC 网络通信能力。四种协议实现完全一致的接口(`network.Server`、`network.Client`、`network.Conn`),网关组件可在不修改业务代码的前提下自由切换。支持心跳检测、TLS 加密、WebSocket 消息压缩、ProxyProtocol 等特性。

## 包路径

```toml
    writeQueueSize = 1024

    heartbeatInterval = "10s"
```

### TCP 服务器示例

```go
package main

import (
    "github.com/dobyte/due/network/tcp/v2"
    "github.com/dobyte/due/v2"
    "github.com/dobyte/due/v2/cluster/gate"
)

func main() {
    // 创建容器
    container := due.NewContainer()
    // 创建TCP服务器
    server := tcp.NewServer()
    // 创建网关组件(网络模块以组件形式集成于网关)
    component := gate.NewGate(
        gate.WithServer(server),
    )
    // 添加网关组件
    container.Add(component)
    // 启动容器
    container.Serve()
}
```

### TCP 客户端示例

```go
package main

import (
    "github.com/dobyte/due/network/tcp/v2"
    "github.com/dobyte/due/v2/log"
)

func main() {
    // 创建TCP客户端
    client := tcp.NewClient(tcp.WithClientAddr("127.0.0.1:3553"))
    // 连接服务器
    conn, err := client.Dial()
    if err != nil {
        log.Fatalf("dial failed: %v", err)
    }
    _ = conn
}
```

## KCP 网络

KCP 基于 UDP 提供可靠传输,适用于移动网络、弱网环境。其接口与 TCP、WebSocket 完全一致。

### 配置参数

```toml
[network.kcp.server]
    # 服务器监听地址,默认为:3553
    addr = ":3553"
    # 服务器最大连接数,默认为5000
    maxConnNum = 5000
    # 写入超时时间,默认为0s(不限制)
    writeTimeout = "0s"
    # 写入队列大小,默认为1024
    writeQueueSize = 1024
    # 心跳检测间隔时间;设置为0则不启用心跳检测,默认为10s
    heartbeatInterval = "10s"
    # 心跳机制,可选:resp | tick。默认为resp
    heartbeatMechanism = "resp"
    # 授权超时时间,默认为0s(不检测)
    authorizeTimeout = "0s"
    # 优雅关闭超时时间,默认为0s(不限制)
    closeTimeout = "0s"
    # 最大传输单元,默认为1400
    mtu = 1400
    # 无延迟模式参数,默认为[1,10,2,1]
    noDelay = [1, 10, 2, 1]
    # 是否启用ACK无延迟,默认不设置
    ackNoDelay = false
    # 是否启用写延迟,默认为true
    writeDelay = true
    # 发送/接收窗口,默认为[32,32]
    windowSize = [32, 32]
    # 读缓冲区大小,默认不设置
    readBuffer = 0
    # 写缓冲区大小,默认不设置
```

## 核心 API

### 服务器接口

```go
// 创建TCP服务器,返回 network.Server
func NewServer(opts ...ServerOption) network.Server

// 创建WebSocket服务器,返回 ws.Server(内嵌 network.Server,额外提供 OnUpgrade)
func NewServer(opts ...ServerOption) ws.Server

// 创建KCP服务器,返回 network.Server
func NewServer(opts ...ServerOption) network.Server

// 创建QUIC服务器,返回 network.Server
func NewServer(opts ...ServerOption) network.Server

// network.Server 接口
type Server interface {
    Addr() string                           // 返回监听地址
    Start() error                           // 启动服务器
    Stop() error                            // 停止服务器
    Protocol() string                       // 返回协议名(tcp/ws/kcp/quic)
    OnStart(handler StartHandler)           // 注册服务器启动回调
    OnStop(handler CloseHandler)            // 注册服务器停止回调
    OnConnect(handler ConnectHandler)       // 注册连接建立回调
    OnHeartbeat(handler HeartbeatHandler)   // 注册心跳到达回调
    OnReceive(handler ReceiveHandler)       // 注册消息到达回调
    OnDisconnect(handler DisconnectHandler) // 注册连接关闭回调
}
```

### 客户端接口

```go
// 创建TCP客户端,返回 network.Client
func NewClient(opts ...ClientOption) network.Client

// 创建WebSocket客户端,返回 network.Client
func NewClient(opts ...ClientOption) network.Client

// 创建KCP客户端,返回 network.Client
func NewClient(opts ...ClientOption) network.Client

// 创建QUIC客户端,返回 network.Client
func NewClient(opts ...ClientOption) network.Client

// network.Client 接口
type Client interface {
    Dial(addr ...string) (Conn, error)      // 连接服务器,addr为空时使用配置中的地址
    Protocol() string                       // 返回协议名
    OnConnect(handler ConnectHandler)       // 注册连接建立回调
    OnHeartbeat(handler HeartbeatHandler)   // 注册心跳到达回调
    OnReceive(handler ReceiveHandler)       // 注册消息到达回调
    OnDisconnect(handler DisconnectHandler) // 注册连接关闭回调
}
```

### 连接接口

```go
type Conn interface {
    ID() int64                     // 连接ID
    UID() int64                    // 绑定的用户ID
    Attr() Attr                    // 连接属性
    Bind(uid int64) error          // 绑定用户ID
    Unbind() error                 // 解绑用户ID
    Push(buf buffer.Buffer) error  // 推送消息
    State() ConnState              // 连接状态
    Close(force ...bool) error     // 关闭连接
    LocalIP() (string, error)      // 本地IP
    LocalAddr() (net.Addr, error)  // 本地地址
    RemoteIP() (string, error)     // 远端IP
    RemoteAddr() (net.Addr, error) // 远端地址
}
```

## 最佳实践

1. **连接管理**:
   - 合理设置 `maxConnNum` 防止资源耗尽
   - 启用心跳检测及时清理死连接

2. **安全性**:
   - 生产环境启用 TLS 加密
   - 配置证书文件确保通信安全

3. **性能优化**:
   - 根据业务需求调整 `readBufferSize`、`writeQueueSize` 等缓冲区参数
   - 合理设置 `writeTimeout`、`closeTimeout` 等超时时间避免阻塞

4. **缓冲区所有权**:
   - `Push` 返回 nil 表示缓冲区所有权已移交网络层,由网络层负责释放;返回错误时由调用方自行释放
   - `OnReceive` 回调接收的缓冲区由业务层负责释放
   - 未注册 `OnReceive` 回调时,收到的消息缓冲区会被自动释放
