# 服务注册 (Registry)

## 概述

服务注册模块是 Due 框架的核心组件,提供服务发现、服务注册、负载均衡等分布式系统基础能力。支持 Consul、Etcd、Nacos、Polaris 等主流注册中心,用于集群实例的服务注册和发现,支撑无感知停服、重启、动态扩容等能力。

## 包路径

```go
import "github.com/dobyte/due/registry/consul/v2"
```

## Consul 注册中心

### 配置参数

```toml
[registry.consul]
    # 客户端连接地址,默认为127.0.0.1:8500
    addr = "127.0.0.1:8500"
    # 是否启用健康检查,默认为true
    healthCheck = true
    # 健康检查时间间隔(秒),仅在启用健康检查后生效,默认为10
    healthCheckInterval = 10
    # 健康检查超时时间(秒),仅在启用健康检查后生效,默认为5
    healthCheckTimeout = 5
    # 是否启用心跳检查,默认为true
    heartbeatCheck = true
    # 心跳检查时间间隔(秒),仅在启用心跳检查后生效,默认为10
    heartbeatCheckInterval = 10
    # 健康检测失败后自动注销服务时间(秒),默认为30
    deregisterCriticalServiceAfter = 30
```

### 使用示例

```go
package main

import (
    "github.com/dobyte/due/registry/consul/v2"
    "github.com/dobyte/due/v2"
    "github.com/dobyte/due/v2/cluster/node"
)

func main() {
    // 创建容器
    container := due.NewContainer()
    // 创建服务注册
    registry := consul.NewRegistry()
    // 创建节点组件
    component := node.NewNode(
        node.WithRegistry(registry),
    )
    // 添加节点组件
    container.Add(component)
    // 启动容器
    container.Serve()
}
```

## 核心 API

### 注册中心接口

```go
type Registry interface {
    // 返回注册发现组件名称
    Name() string
    // 注册服务实例
    Register(ctx context.Context, ins *ServiceInstance) error
    // 注销服务实例
    Deregister(ctx context.Context, ins *ServiceInstance) error
    // 监听同名服务实例变化
    Watch(ctx context.Context, serviceName string) (Watcher, error)
    // 获取服务实例列表
    Services(ctx context.Context, serviceName string) ([]*ServiceInstance, error)
    // 关闭注册发现组件
    Close() error
}
```

### 服务实例结构

```go
type ServiceInstance struct {
    ID       string            // 服务实例ID
    Name     string            // 服务名称
    Kind     string            // 服务实体类型
    Alias    string            // 服务实体别名
    State    string            // 服务实例状态
    Events   []int             // 服务事件集合
    Routes   []Route           // 服务路由ID
    Services []string          // 服务路由列表
    Endpoint string            // 微服务实体暴露端口
    Weight   int               // 服务路由加权轮询权重
    Metadata map[string]string // 元数据
}

type Route struct {
    ID         int32 // 路由ID
    Internal   bool  // 是否为内部路由
    Stateful   bool  // 是否为有状态路由
    Authorized bool  // 是否需要鉴权
}
```

### Watcher 接口

```go
type Watcher interface {
    // 获取下一个服务实例列表
    Next() ([]*ServiceInstance, error)
    // 停止监听
    Stop() error
}
```

## 服务注册示例

```go
package main

import (
    "context"

    "github.com/dobyte/due/registry/consul/v2"
    "github.com/dobyte/due/v2/registry"
)

func main() {
    // 创建注册中心
    reg := consul.NewRegistry()

    // 注册服务
    err := reg.Register(context.Background(), &registry.ServiceInstance{
        ID:       "service-1",
        Name:     "my-service",
        Kind:     "node",
        Endpoint: "127.0.0.1:8080",
        Weight:   1,
        Metadata: map[string]string{
            "version": "v1.0.0",
        },
    })
    if err != nil {
        panic(err)
    }

    // 获取服务列表
    services, err := reg.Services(context.Background(), "my-service")
    if err != nil {
        panic(err)
    }
    for _, ins := range services {
        println("service instance:", ins.ID)
    }

    // 监听服务变化
    watcher, err := reg.Watch(context.Background(), "my-service")
    if err != nil {
        panic(err)
    }
    defer watcher.Stop()

    for {
        instances, err := watcher.Next()
        if err != nil {
            break
        }
        // 处理服务变更
        handleServiceChange(instances)
    }
}
```

## 最佳实践

1. **服务命名**:
   - 使用清晰的服务名称便于识别
   - 服务ID应全局唯一

2. **健康检查**:
   - 启用健康检查确保服务可用性
   - 合理设置检查间隔和超时时间

3. **元数据管理**:
   - 控制元数据数量(建议不超过20个)
   - 键长度不超过127字符,值长度不超过512字符

4. **高可用**:
   - 配置自动注销时间防止僵尸服务
   - 使用心跳机制保持服务活性
